# Application assets

The default UI presets use aging cyber monk, default target, Jack
(`optimus.png`), Jane (`mashr-female.png`), and the warehouse background.
The optimised portraits are original fictional adults generated for clean face
detection and swapping. Older target images may remain locally but are not offered
as presets. User uploads, avatar profiles, voice references, render
outputs, recordings and other local images are excluded from Git.

Face-swap, background and speech model weights are not included. Follow the
repository README and model setup documentation to install the required local
runtimes and supply the model assets separately.
