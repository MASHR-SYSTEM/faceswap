# Everyday use

1. Launch FaceSwap; open its local browser window.
2. Select Automatic (standard webcam), or explicitly select another camera.
3. In Setup & help select Camera preview, Cartoon, Privacy blur or Neural face swap.
4. For neural mode, supply the optional models and upload a permitted target image.
5. Start camera. Transformation blends between original and the model's full swap.
6. Choose a background image if segmentation is installed. Off retains it; Remove
   clears it. Cancelling the file picker leaves the current selection unchanged.
7. For call output, enable Virtual camera and apply/restart. Select the virtual
   camera in your receiving application. Voice starts separately.
8. Camera/output and voice edits show Changes apply on restart. Use their Apply &
   restart actions. Face transformation controls update live.
9. Stop all stops camera, voice and any speech work. Exit in the launcher closes
   the application. A Stopping status means resources are still being released;
   do not launch a second capture owner.

The control tree scrolls independently on desktop. Metadata is available in its
own collapsed category. Avatar Studio and saved preset controls are not part of
this release. Vertical, smoothing and temporal smoothing remain fixed.
